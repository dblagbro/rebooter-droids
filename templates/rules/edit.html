Probe shape reference

Copy-paste starting points for the "probe" block in the JSON editor above. The structured form covers the network probes + Roku / HA-state / weather / iCal / EPG / power kinds — these cards are mainly for the JSON-only kinds (host_awake, ha_numeric_*, solar_*, snmp_*, media_session_active, webhook_field_equals, mqtt_topic_equals) plus a quick reference for everything else. v0.5.101 backfilled the remaining ~16 kinds from KNOWN_PROBE_KINDS.

{# ── Network probes (no source_id — direct from this hub) ──────── #}
internet 
"probe": {
  "kind": "internet",
  "targets": [
    {"host": "1.1.1.1", "port": 53},
    {"host": "8.8.8.8", "port": 53},
    {"host": "4.2.2.2", "port": 53}
  ]
}

Outbound TCP-connect to each target; succeeds if any succeeds, fails only when all fail. targets defaults to the three public-DNS resolvers above if omitted.

ping 
"probe": {
  "kind": "ping",
  "host": "192.168.1.1"
}

Native ICMP ping (v0.5.13 — B6.1). Requires the container's raw-socket capability; falls back to TCP-connect on hosts where it can't open a raw socket.

tcp 
"probe": {
  "kind": "tcp",
  "host": "10.0.0.1",
  "port": 22
}
http 
"probe": {
  "kind": "http",
  "url": "https://example.com/healthz"
}

Succeeds on a 2xx response within the probe timeout.

dns 
"probe": {
  "kind": "dns",
  "hostname": "example.com"
}
gateway 
"probe": {
  "kind": "gateway"
}

Pings the device's LAN gateway (resolved from the device's most recent heartbeat). No host needed.

snmp_interface_down 
"probe": {
  "kind": "snmp_interface_down",
  "source_id": "ext_…",
  "if_name": "eth1",
  "max_sample_age_seconds": 600
}

Source must be an snmp integration (v0.5.58, P2.2/P2.3). Succeeds when the named interface's ifOperStatus is anything other than up. UniFi gear serves SNMP only once the controller has SNMPv1/v2c enabled.

snmp_throughput_above 
"probe": {
  "kind": "snmp_throughput_above",
  "source_id": "ext_…",
  "if_name": "eth1",
  "direction": "in",
  "threshold_bps": 50000000,
  "max_sample_age_seconds": 600
}

direction is "in" or "out"; threshold_bps is bits-per-second. Matching snmp_throughput_below exists for the inverse.

snmp_throughput_below 
"probe": {
  "kind": "snmp_throughput_below",
  "source_id": "ext_…",
  "if_name": "eth1",
  "direction": "in",
  "threshold_bps": 100000,
  "max_sample_age_seconds": 600
}
snmp_error_rate_above 
"probe": {
  "kind": "snmp_error_rate_above",
  "source_id": "ext_…",
  "if_name": "eth1",
  "threshold_errors_per_minute": 5,
  "max_sample_age_seconds": 600
}

Succeeds when the named interface's combined in+out error counter grows faster than threshold_errors_per_minute across the two most-recent SNMP samples.

media_session_active 
"probe": {
  "kind": "media_session_active",
  "source_id": "ext_…",
  "max_sample_age_seconds": 600
}

Source must be a plex or jellyfin webhook integration (v0.5.61). Succeeds while a play / resume webhook has arrived within max_sample_age_seconds and no pause / stop has superseded it. A reboot rule using this fires only while nothing is playing.

webhook_field_equals 
"probe": {
  "kind": "webhook_field_equals",
  "source_id": "ext_…",
  "field": "payload.state",
  "expected_value": "armed",
  "max_sample_age_seconds": 900
}

For custom webhook integrations (iOS Shortcut and any operator-defined source kind). field is a dotted path into the most-recent inbound JSON payload; equality is case-insensitive.

{# v0.5.32 (B16 Phase 1D): power-targeted probes. #}
power_above 
"probe": {
  "kind": "power_above",
  "device_id": "dev_…",
  "threshold_w": 1500,
  "window_seconds": 300,
  "max_sample_age_seconds": 600
}

Fires when avg watts over window_seconds exceeds threshold_w. Stale samples (older than max_sample_age_seconds) return failure with reason='stale_sample'.

power_below 
"probe": {
  "kind": "power_below",
  "device_id": "dev_…",
  "threshold_w": 5,
  "window_seconds": 600,
  "max_sample_age_seconds": 600
}

Fires when avg watts over window_seconds is under threshold_w. Useful for "is the device actually drawing power?".

power_zero_while_on 
"probe": {
  "kind": "power_zero_while_on",
  "device_id": "dev_…",
  "near_zero_threshold_w": 0.5,
  "window_seconds": 300,
  "max_sample_age_seconds": 600
}

"Phantom failure" detector: fires when relay_on is true but the device is drawing near zero. Catches appliances that died while the smart-plug relay is still energized.

{# v0.5.62 (B17 Ship 4): host_awake — a direct TCP-connect probe, no external-sensor source needed. #}
host_awake 
"probe": {
  "kind": "host_awake",
  "host": "192.168.1.50",
  "port": 22
}

TCP-connect check — succeeds while the host is reachable (powered on / awake). port is optional, defaults to 22 (SSH). No source_id needed — it probes the host directly. A reboot rule using this fires only while the host is OFF (e.g. "don't power-cycle the office switch while the work laptop is on").

{# v0.5.63 (B17 Ship 3): MQTT topic probe. #}
mqtt_topic_equals 
"probe": {
  "kind": "mqtt_topic_equals",
  "source_id": "ext_…",
  "topic": "garage/door/state",
  "expected_value": "open",
  "max_sample_age_seconds": 300
}

Succeeds when the most-recent message on topic (within max_sample_age_seconds) equals expected_value (case-insensitive). Source must be an mqtt integration.

{# v0.5.64 (B17 Layer 2): EPG show-airing probe. #}
epg_show_airing 
"probe": {
  "kind": "epg_show_airing",
  "show": "Jeopardy",
  "network": "ABC"
}

Succeeds while a show matching show (title substring, case-insensitive) is airing now per the TVMaze EPG cache. network is optional — restricts to one TVMaze network. No source_id — the EPG cache is global.

Find your source_ids at Settings → Integrations →. device_ids are on the Devices → page.
