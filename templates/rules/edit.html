Probe shape reference

Quick reference for the four integration probe kinds shipped in v0.5.17 + v0.5.23. Use these as a starting point when editing the JSON above; full per-kind structured-form on this page is queued for a future ship.

roku_app_active 
"probe": {
  "kind": "roku_app_active",
  "source_id": "ext_…",
  "app_name": "Spectrum TV",
  "max_sample_age_seconds": 120
}
ha_state_is 
"probe": {
  "kind": "ha_state_is",
  "source_id": "ext_…",
  "entity_id": "sensor.living_room_motion",
  "expected_state": "on",
  "max_sample_age_seconds": 60
}
weather_alert_active 
"probe": {
  "kind": "weather_alert_active",
  "source_id": "ext_…",
  "event_contains": "Storm",
  "min_severity": "Severe",
  "max_sample_age_seconds": 600
}

event_contains + min_severity are both optional. Severity ladder: Minor < Moderate < Severe < Extreme.

ical_event_active 
"probe": {
  "kind": "ical_event_active",
  "source_id": "ext_…",
  "summary_contains": "Jeopardy",
  "max_sample_age_seconds": 1800
}

summary_contains is optional — empty matches any currently-airing event.

{# v0.5.32 (B16 Phase 1D): power-targeted probes. #}
power_above 
"probe": {
  "kind": "power_above",
  "device_id": "dev_…",
  "threshold_w": 1500,
  "window_seconds": 300,
  "max_sample_age_seconds": 600
}

Fires when avg watts over window_seconds exceeds threshold_w. Stale samples (older than max_sample_age_seconds) return failure with reason='stale_sample'.

power_below 
"probe": {
  "kind": "power_below",
  "device_id": "dev_…",
  "threshold_w": 5,
  "window_seconds": 600,
  "max_sample_age_seconds": 600
}

Fires when avg watts over window_seconds is under threshold_w. Useful for "is the device actually drawing power?".

power_zero_while_on 
"probe": {
  "kind": "power_zero_while_on",
  "device_id": "dev_…",
  "near_zero_threshold_w": 0.5,
  "window_seconds": 300,
  "max_sample_age_seconds": 600
}

"Phantom failure" detector: fires when relay_on is true but the device is drawing near zero. Catches appliances that died while the smart-plug relay is still energized.

{# v0.5.62 (B17 Ship 4): host_awake — a direct TCP-connect probe, no external-sensor source needed. #}
host_awake 
"probe": {
  "kind": "host_awake",
  "host": "192.168.1.50",
  "port": 22
}

TCP-connect check — succeeds while the host is reachable (powered on / awake). port is optional, defaults to 22 (SSH). No source_id needed — it probes the host directly. A reboot rule using this fires only while the host is OFF (e.g. "don't power-cycle the office switch while the work laptop is on").

{# v0.5.63 (B17 Ship 3): MQTT topic probe. #}
mqtt_topic_equals 
"probe": {
  "kind": "mqtt_topic_equals",
  "source_id": "ext_…",
  "topic": "garage/door/state",
  "expected_value": "open",
  "max_sample_age_seconds": 300
}

Succeeds when the most-recent message on topic (within max_sample_age_seconds) equals expected_value (case-insensitive). Source must be an mqtt integration.

Find your source_ids at Settings → Integrations →. device_ids are on the Devices → page.
