Device scenes

A scene is a named set of per-device target states. A watchdog apply_scene action — or a binding rule's edge — applies one, so "Erica's TV audio" can be authored once and reused. Reference a scene from a rule with {"kind": "apply_scene", "scene_id": "<id below>"}.
