What happens next

  1. Mint a token — the portal issues a one-shot enrollment secret.
  2. Configure the device — paste the token plus the central URL into the device's onboarding flow (firmware web UI on the LAN, or via serial bring-up).
  3. First heartbeat — once the device registers, the portal swaps the enrollment token for a long-lived device bearer token. The enrollment token can then be discarded.
  4. You're done — the device shows up on the Devices list and on the Status page.

Don't have serial / web access to the device? Flash unprovisioned firmware and let it announce itself, then adopt from /app/pending-adoption with one click.
