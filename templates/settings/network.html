Public URLs the hub serves on, CORS allowlist, and rate-limit exemption list.

Live now

  • Strict CORS allowlist — REBOOTER_CORS_ALLOWED_ORIGINS, env-var-driven (v0.2.11).
  • Dual canonical hosting — REBOOTER_PUBLIC_BASE_URL + REBOOTER_FIRMWARE_PUBLIC_BASE, both nodes mirror; device-side fallback queries primary then secondary (RFC-002 P1).
  • Security headers on every response — HSTS, X-Frame-Options DENY, X-Content-Type-Options, Referrer-Policy, and a tightened CSP (script-src 'self', no 'unsafe-inline'; v0.4.11 + v0.4.22).
  • Rate-limit exemption list — REBOOTER_RATE_LIMIT_EXEMPT_IPS for the QA host (v0.4.4). Empty by default in any internet-facing deployment.
