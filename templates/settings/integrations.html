The Roku ECP API is unauthenticated and LAN-local. Click Probe now after adding to verify reachability — the next live sample will appear above.

{# ── Home Assistant (v0.5.23) ──────────────────────────────────────── #}

Add a Home Assistant instance

Mint a long-lived token in HA: Profile → Long-Lived Access Tokens → Create. Token is stored DB-side and masked in the source row above. Hub polls /api/states at the chosen cadence and caches a compact entity dictionary the watchdog probe ha_state_is can match against.

{# ── Weather alerts (NWS) ──────────────────────────────────────────── #}

Add a Weather feed (NWS active alerts)

US-only — uses api.weather.gov/alerts/active?point=lat,lng (no auth required, NWS asks for a User-Agent that identifies the project). 10-min poll interval is appropriate; alerts don't change minute-by-minute. Rule probe: weather_alert_active with optional event_contains and min_severity.

{# ── iCal / WebCal ────────────────────────────────────────────────── #}

Add an iCal / WebCal feed

Any HTTP(S) or webcal:// .ics feed: Google Calendar (Settings → Secret address in iCal format), Apple iCloud, Outlook web. Hub fetches at the chosen cadence and parses VEVENTs. Storage is capped at 50 events per sample; only events airing in the next 24 h are retained. Rule probe: ical_event_active with summary_contains filter.

{# ── SolarEdge (cloud) ────────────────────────────────────────────── #}

Add a SolarEdge site (cloud)

Polls monitoringapi.solaredge.com/site/{id}/overview. Generate the API key in the SolarEdge monitoring portal (Admin → Site Access → API Access). The API key is stored encrypted-at-rest and never shown back. Rate limit: 300 requests/day — keep the interval ≥ 300 s. Rule probe: solar_production_above / solar_production_below.

{# ── Enphase Envoy (local) ────────────────────────────────────────── #}

Add an Enphase Envoy (local)

Polls the Envoy's local /production.json — no cloud round-trip. Legacy Envoys need no auth; firmware-7.0+ Envoys require a JWT (minted at enlighten.enphaseenergy.com) and serve HTTPS. Metered gateways report an accurate eim reading; others fall back to the inverter sum. Rule probe: solar_production_above / solar_production_below.

{# ── SNMP (router / managed switch) ───────────────────────────────── #}

Add a router / managed switch (SNMP)

SNMP v3 fields (only if Version = v3)

Polls the standard SNMP IF-MIB interface table (uptime, per-interface link state, 64-bit traffic + error counters). Works with managed switches and prosumer routers — Ubiquiti UniFi (enable SNMP v1/v2c in the UniFi Network controller: Settings → System), MikroTik, OpenWrt, pfSense/OPNsense. Community strings + v3 keys are stored encrypted-at-rest and never shown back. Rule probes: snmp_interface_down, snmp_throughput_above/below, snmp_error_rate_above.

{# ── Webhook integrations (Plex / Jellyfin / iOS Shortcuts) ───────── #}

Add a webhook integration (Plex / Jellyfin / iOS Shortcuts)

No host needed — these push to the hub. On Add the hub mints a per-source secret; the integration row then shows the inbound URL and the X-Webhook-Secret header value to paste into the sender:

  • Plex — Settings → Webhooks → Add Webhook → paste the URL. Plex POSTs multipart; the secret goes in the X-Webhook-Secret header (use a webhook proxy/Shortcut if your Plex can't set headers).
  • Jellyfin — install the Webhook plugin → add a Generic Destination → set the URL and add the X-Webhook-Secret header.
  • iOS Shortcuts — a "Get Contents of URL" action, POST, JSON body (e.g. {"state":"home"}), with the X-Webhook-Secret header.

Rule probes: media_session_active (Plex/Jellyfin — succeeds while a movie is playing, so a reboot rule fires only when idle); webhook_field_equals (generic — match any JSON field, e.g. iOS Shortcut state=home).

{# ── MQTT broker subscriber ───────────────────────────────────────── #}

Add an MQTT broker subscriber

A background subscriber holds an open connection to your broker (e.g. Mosquitto on your Home Assistant host) and records every message on the subscribed topics. Topic filters support MQTT wildcards (+, #). Credentials are stored encrypted-at-rest. Rule probe: mqtt_topic_equals. Note: adding or editing an MQTT source takes effect on the next container restart (the subscriber list is read at start-up).

How to use this in a watchdog rule

Add a probe of kind roku_app_active to a watchdog rule: 

{
  "kind": "roku_app_active",
  "source_id": "ext_…",
  "app_name": "Spectrum TV",
  "max_sample_age_seconds": 120
}

The probe succeeds (rule armed → recovery) when the latest sample is recent and the active app name contains app_name (case-insensitive substring). Pair with a schedule for "Jeopardy is on" rules (e.g. weekdays 19:00–19:30) using the existing schedules primitive.

For a solar source, use a solar_production_above / solar_production_below probe: 

{
  "kind": "solar_production_above",
  "source_id": "ext_…",
  "threshold_w": 3000,
  "max_sample_age_seconds": 1800
}

Mirrors the B16 power_above/power_below shape — pairs naturally with power monitoring (load) to act on the generation-minus-load delta, e.g. "exporting > 3 kW → switch on the water heater."

For an SNMP source, watch a router/switch interface — the classic "reboot the modem when the WAN link drops": 

{
  "kind": "snmp_interface_down",
  "source_id": "ext_…",
  "interface": "wan",
  "max_sample_age_seconds": 600
}

The probe fails (rule builds toward its action) when the named interface's link state is not up. Throughput (snmp_throughput_above/below) and error-rate (snmp_error_rate_above) probes compare a rate computed from the last two samples — point the action at the modem's plug for auto-recovery.
