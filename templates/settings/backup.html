Backup & restore configuration

Export the hub's operator-managed configuration to a portable JSON file — for migration, disaster recovery, or self-host setup — and import it back. This is config portability, not a database dump: it covers settings, watchdog rules, schedules, scenes, sites/groups and per-device desired config (keyed by MAC). It deliberately does not include devices, users, credentials, heartbeats, power data or the audit log.

Export

By default secrets (SMTP password, HMAC keys, API tokens, source credentials) are redacted from the export. To include them, the file is AES-GCM encrypted with a passphrase you supply — keep that passphrase safe; it is never stored.
