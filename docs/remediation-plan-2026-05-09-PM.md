## What was NOT found in this sweep (worth knowing)

To be candid about coverage: the following surfaces were NOT
deeply exercised in this run:

- **Watchdog probe runtime end-to-end** (v0.4.2). Probe-now path
  tested. The cron-tick path was not — would require waiting
  for several 10 s windows to observe state-machine transitions.
- **Multi-hub sync** (RFC-004). Pre-implementation; no test
  scaffolding.
- **Firmware OTA download → apply → verify** end-to-end. Mirror
  URL shapes tested; no real device-side exercise.
- **CSRF protection** on form-POST endpoints — Flask has no
  per-request token enforcement that I see. Would be worth a
  separate hardening pass.
- **CORS allowlist edge cases** (v0.2.11) — there's a focused
  test file but I didn't re-validate.
- **Cookie SameSite + Secure flags** end-to-end behavior across
  cross-origin requests.
- **Observability under load** — no load test was attempted.

These are coverage gaps to log against future deep regressions
(repeat this exercise quarterly or per-major-release).
